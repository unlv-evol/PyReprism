============
Metrics
============

:meth:`~PyReprism.languages.base.BaseLanguage.stats` (and
:func:`PyReprism.stats`) return a :class:`~PyReprism.metrics.CodeStats` with
line- and token-level metrics, suitable for building code datasets.
